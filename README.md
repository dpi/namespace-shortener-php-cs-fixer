# dpi/namespace-shortener-php-cs-fixer

[![Packagist Version](https://img.shields.io/packagist/v/dpi/namespace-shortener-php-cs-fixer)](https://packagist.org/packages/dpi/namespace-shortener-php-cs-fixer)
[![Documentation](https://img.shields.io/badge/docs-website-blue)](https://dpi.github.io/namespace-shortener/)

The [PHP-CS-Fixer](https://cs.symfony.com/) rule for Namespace Shortener, which imports the namespaces you choose, and rewrites every usage to go through them.

## Install

```sh
composer require --dev dpi/namespace-shortener-php-cs-fixer
```

## Documentation

Read the documentation at [dpi.github.io/namespace-shortener](https://dpi.github.io/namespace-shortener/).
